{{ .Chart.Name }} {{ .Chart.AppVersion }} is deployed as "{{ .Chart.Name }}".

Port-forward to try it locally:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ .Chart.Name }} 8000:{{ .Values.service.port }}

Then (API key = the value you passed as apiKey):

  curl -s -H "X-API-Key: $API_KEY" -F "file=@./somefile.pdf" http://localhost:8000/api/v1/files
  curl -s -H "X-API-Key: $API_KEY" -H "Content-Type: application/json" \
       -d '{"expires_in_seconds": 300}' http://localhost:8000/api/v1/files/<file_id>/links
